
## Dataset

This project uses the **ASL Alphabet Dataset** by Akash Nagaraj (~87,000 images, 29 classes: A–Z plus SPACE, DELETE, NOTHING):

👉 https://www.kaggle.com/datasets/grassknoted/asl-alphabet

**The dataset is not included in this repository** — it's roughly 1GB in size, well beyond what's practical to version-control on GitHub. To set up the project:

1. Download the dataset from the Kaggle link above.
